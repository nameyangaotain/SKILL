# 学术翻译规范

供译员角色执行时遵循的细则。凡是与用户当次指令冲突的，以用户指令为准。

## 一、术语处理

| 情形 | 处理方式 | 示例 |
| --- | --- | --- |
| 有公认中文译名的普通专业词 | 首次「中文（English）」，之后纯中文 | 检索增强生成（retrieval-augmented generation）→ 检索增强生成 |
| 已被中文文献广泛使用的缩略语 | 首次「中文全称（ABBR）」，之后用 ABBR | 大语言模型（LLM）→ LLM |
| 模型名 / 软件名 / 数据库名 / 算法名 | 保留原文，不译 | HAIant、Qwen3-0.6B、DeepSeek、BLAST、FASTA |
| 基因 / 蛋白 / 品种 / 菌株名 | 保留原文与大小写、斜体约定 | OsNAC2、Arabidopsis thaliana |
| 人名 | 首次出现译名 + 原文 | 张云龙（Yunlong Zhang） |
| 机构名 | 译出，首次附原文 | 华中农业大学（Huazhong Agricultural University） |
| 期刊名 | 保留原文缩写 | Mol. Plant、Nature |
| 公司 / 产品名 | 保留原文 | CellPress、GitHub |
| URL / DOI / 邮箱 / 版本号 | 原样保留 | https://doi.org/10.1016/... |
| 自定义指标名 | 保留英文原词 + 中文解释性括注 | PP512（512 输入 token 的提示处理吞吐量） |

**一致性优先于优美。** 同一概念在全文中只允许一种译法。发现前后不一致时，以首次出现的译法为准并全文回改。

## 二、数字与统计

- 数字、百分比、小数位、置信区间、P 值原样保留：`92.3%` 不写成「约九成」。
- 数量级与单位符号保留：`386.81 tokens/s`、`84 tools`、`Q4_K_M` 量化。
- 括号内的样本量 `(n = 100)` 保留为 `（n = 100）`，只换括号字形，不动内容。
- 范围连接号统一用「–」，但数值本身不变。

## 三、交叉引用与引文

- `(Figure 1A)` → `（图 1A）`，与中文图题编号保持一致；若正文用「图 1A」，图题也用「图 1」。
- `(Table 2)`、`(Supplemental Video 1)`、`(Supplemental Table 1)` 同理。
- 作者年份引用 `(Zhang et al., 2024)` **原样保留英文**，不译为「（张等，2024）」。
- 参考文献列表整体不翻译，保持原文，仅保证编号与正文一致。

## 四、语体

- 用「本研究」「本文」指代论文自身，避免「我们」满篇；作者自述实验时可用「我们」，但同一段内保持一致。
- 摘要用陈述句，不用「本文旨在…」之外的套话；不添加原文没有的评价词（如「具有重要意义」）。
- 被动语态按中文习惯转为主动或有条件保留，不逐字硬译。
- 长句可拆分，但不得改变逻辑关系（因果、让步、转折必须保留）。
- 中文标点：使用全角标点；英文原文的引号、破折号按中文规范改写；公式与英文原文内部标点不动。

## 五、结构对齐

- **标题**：层级与原文一致。一级节标题全大写者译为中文常规大小写。
- **图注**：`Figure 1.` → `图 1.`；分图说明 `(A)…(B)…` 保持并列结构，每项以分号或句号分隔，与原文一致。
- **表注**：同图注，`Table 1.` → `表 1.`。
- **摘要**：单独成段，不分节。
- **关键词**：`Key words:` → `关键词：`，词条之间用中文顿号或逗号，术语保留原文。
- **占位符与方括号**：原文中的 `[ ]`、`†`、`*` 等标记保留。

## 六、分栏片段（原位对照模式专用）

原位对照模式下，一个段落被分栏切断时会拆成两个块，各自回填到原栏的矩形里。读者按「左栏末 → 右栏首」的顺序读，所以两段译文必须能接得起来。

- **在原文断开的位置断开。** 不要为了通顺把整句挪到后半段，否则前半段会留下大片空白。
- **原文断在半个词上时中文照做。** `…by integrating ma-` / `chine learning…` → `…通过整合机` / `器学习…`。拼起来仍是「机器学习」。
- **不要把后半段写成独立完整的句子。** 避免出现「上一段以句号收尾、下一段另起一句」的割裂感。
- 高度结构化的段落（实验步骤、参数列表）切点通常落在分号或逗号处，按原文标点切即可。

判断切点是否合理：把两段中文连起来读一遍，若和通读全文一样自然，就对了。

## 七、禁止事项

1. 禁止增删信息，禁止补全作者未写的推论。
2. 禁止把图表注里的英文改写成中文图内文字（图内文字不译）。
3. 禁止翻译参考文献条目、DOI、URL、邮箱。
4. 禁止输出「（此处略）」「（略）」等省略标注。
5. 禁止把块合并或拆分：一个块的译文只能写在一个键下。
6. 禁止翻译图内标注（流程图框、坐标轴、色标、示意图标签）。
7. 禁止从拼音反推作者中文姓名；作者姓名一律保留拉丁原文。
