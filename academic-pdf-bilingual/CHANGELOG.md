# Changelog

版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [1.0.0] — 2026-09-11

首个可用版本。以《Molecular Plant》2026 年一篇 12 页双栏校样论文（HAIant / 智然体）
作为端到端验证样本，成品与 BabelDOC v0.6.4 dual 输出的页面规格一致
（12 页、1224×783pt），体积 7.0MB（参照件 14.7MB）。

### 新增

- **原位对照模式**（默认）：`scripts/compose.py`
  - 左半原页逐像素复制，右半同版式原地替换为中文，页数与原文 1:1
  - 中文按原文本框自适应缩放，逐 0.2pt 试算取最大可用字号
  - 擦除矩形按图区收缩，保证不啃到插图
  - 背景色采样，有色背景上不留白疤
  - 按颜色分组写 TextWriter，保留标题原有配色
  - 字体子集化，成品体积从 20.8MB 降至 7.0MB
- **重排对照模式**：`scripts/render.py`，A3 横向逐段对齐，插图通栏
- **结构化解析**：`scripts/extract.py`
  - `--profile inplace`：保持 PDF 自然块、不做跨栏合并（原位替换的硬性前提）
  - `--profile reflow`：跨栏片段合并为完整段落
  - 分栏阅读顺序按"全宽元素分段 + 段内按栏排序"还原
  - 图区由"图注上方空白带"推断，不依赖不可靠的 `get_image_info()`
  - 跨行断词合并，含 100+ 条复合词保护表
- **译稿质检**：`scripts/check.py`，校验覆盖度、数字、交叉引用、图表编号、术语一致性
- **译员角色库**：`references/translator-personas.md`，15 个学科到译员角色的映射与提示词模板
- **翻译规范**：`references/translation-rules.md`，术语 / 数字 / 交叉引用 / 语体 / 分栏片段处理
- **一键安装**：`install.py`，支持用户级与项目级安装

### 已知问题

- 原位模式下右半会因译文较短而留白（格式固有特征）
- 分栏切断的段落拆成两段译，需保证在原文断开处断开
- 跨页大表的单元格可能被拆成多个块，译文可读但不理想
- 不支持扫描件（需 PDF 有文字层）
